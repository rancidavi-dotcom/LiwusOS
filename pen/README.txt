PEND DRIVE VIRTUAL
==================

ARRASTE músicas .mp3 para esta pasta enquanto o LiwusOS está rodando.
O sistema detecta a mudança e o Pendrive Virtual aparece no app
"Multimedia" junto com as músicas de fábrica — tudo ao vivo, sem reiniciar.

Para retirar uma música: apague o arquivo desta pasta (o pendrive
virtual some da lista).

Aviso: o pendrive é somente leitura dentro do LiwusOS. As músicas
ficam em pendrive.img na raiz do projeto (regerada a cada mudança).
