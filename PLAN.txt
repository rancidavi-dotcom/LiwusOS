Missão

Quero transformar a infraestrutura gráfica do LiwusOS em uma arquitetura de nível profissional.

Não quero apenas adicionar funcionalidades.

Quero criar uma fundação que permita o sistema evoluir pelos próximos anos sem precisar ser reescrito.

Imagine que você está projetando a infraestrutura gráfica do LiwusOS para durar uma década.

Não pense como alguém criando um hobby OS.

Pense como um arquiteto que está projetando o equivalente ao compositor, sistema gráfico, toolkit e runtime de um sistema operacional moderno.

Contexto

O LiwusOS não utilizará X11, Wayland, Quartz, Win32, Cocoa, GTK ou Qt.

Tudo será nativo.

O objetivo não é copiar Linux ou Windows.

O objetivo é criar uma arquitetura própria.

A interface será baseada em um Canvas Infinito, onde todos os elementos do sistema vivem em um mesmo espaço navegável.

API

Toda a infraestrutura deve parecer uma SDK.

Se amanhã eu criar um aplicativo, quero escrever algo como:

Canvas* canvas = canvas_create();

Node* node = text_create("Olá");

canvas_add(canvas, node);

camera_zoom(canvas, 2.0f);

node_move(node, 500, 300);

A API deve ser limpa, consistente e intuitiva.
